# Browser Proxy Development

## Setup

```bash
npm install
```

## Running

### Development
```bash
npm run dev
```
Open http://localhost:3000 in your browser

### Production
```bash
npm run build
npm run start
```

## How to Use

1. Start the proxy server
2. Open Chrome (or any browser) to http://localhost:3000
3. Enter a URL in the address bar (e.g., `google.com`, `github.com`, `wikipedia.org`)
4. Press Enter or click "Go"
5. The webpage will load through the proxy
6. Use the back/forward/reload buttons to navigate
7. Open new tabs with the "+" button

## Features

- ✅ Proxy any website
- ✅ Tabbed browsing
- ✅ Browser history (back/forward)
- ✅ URL rewriting for links and forms
- ✅ Cookie and session management
- ✅ Clean, intuitive UI

## Architecture

```
Client (Browser)
    ↓
    └→ http://localhost:3000
         ├→ Frontend: React UI (tabs, address bar, navigation)
         └→ Backend: /api/proxy endpoint
              ↓
              └→ Fetches any website
                   ↓
                   └→ Rewrites URLs
                        ↓
                        └→ Returns to iframe
```
